# Sherpa documentation

The [README](../README.md) covers installing Sherpa, the first run and the
commands. These pages cover the rest:

- **[Concepts](concepts.md)**: how Sherpa works. It covers the agent loop,
  the tools, permissions, the context window, memory, documentation search and
  sessions.
- **[How-to guides](how-to.md)**: recipes for specific tasks. It covers
  several providers, a local model, a project that runs in a container, skills,
  MCP servers, measuring documentation search on your own project, and keeping
  an eye on cost.
- **[Design choices](design-choices.md)**: what was decided while building
  an AI agent, and the measurements behind each decision. It also lists what was
  tried and rejected.
