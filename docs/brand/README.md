# Sherpa's logo

The mark is a mountain whose summit stands apart, in green: where the guide takes you. It is drawn like
[Airlock](https://github.com/hbenabdallah/airlock)'s: the same tile, stroke and round caps, ink and paper, one accent.

| File | Use |
|---|---|
| `logo.svg` | The lockup (mark and wordmark) on light backgrounds |
| `logo-dark.svg` | The lockup on dark backgrounds |
| `mark.svg`, `mark-dark.svg` | The mark alone, on light or dark backgrounds |
| `icon.svg` | The app icon: the mark on a dark tile |
| `acp-icon.svg` | The ACP registry's icon (`sherpa/icon.svg` there): the mark at 16 × 16, in `currentColor` only, so editors theme it |
| `icon-512.png` | The GitHub avatar (square; GitHub rounds it) |
| `social-preview.png` | The repository's social preview, 1280 × 640 |

The wordmark is drawn as paths, so the SVGs need no font: Space Grotesk SemiBold for `sherpa`, JetBrains Mono for
the tagline on the social preview (both under the SIL Open Font License).

| Colour | Hex |
|---|---|
| Ink | `#12161C` |
| Paper | `#F6F5F1` |
| Green, on light | `#6E8C0E` |
| Green, on dark | `#AFD75F`, the terminal's green and the installs badge's |

On GitHub: the avatar is set in the account's or organisation's profile settings, the social preview in the
repository's Settings, General, Social preview.
